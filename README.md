# 루쿠 NFC 룰렛 — 서버 없는 버전

## 기능
- 웹페이지를 새로 열거나 새로고침하면 룰렛이 **한 번 자동 회전**합니다. 쿨타임은 없습니다.
- 보상 확률: 일반 포토카드 40%, 파란 나뭇잎 25%, 레어 포토카드 18%, 암호 힌트 10%, 히든 룸 열쇠 6%, 시크릿 카드 1%.
- 당첨 결과는 해당 브라우저의 `localStorage`에 누적됩니다. 다른 기기나 브라우저로 옮겨지지 않습니다.
- 별도 로그인, Firebase, 데이터베이스, 서버 함수가 필요 없습니다.
- `index.html`, `style.css`, `app.js` 세 파일이 전부입니다.

## 무료 공개 방법 (GitHub Pages 예시)
1. GitHub에서 공개 저장소를 새로 만듭니다.
2. 세 파일을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Build and deployment에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
4. 발급된 `https://계정.github.io/저장소명/` 주소를 스마트폰에서 열어 테스트합니다.
5. NFC Tools 등 NFC 기록 앱으로 태그에 **URL/URI 레코드**를 기록합니다.
6. NFC를 태그해 페이지가 열리는지 확인합니다. 휴대폰에 따라 링크 열기 확인이 필요합니다.

## 주의
- 브라우저는 NFC 태그를 찍었는지 구분하지 않습니다. 링크를 직접 열거나 새로고침해도 1회 회전합니다.
- 일반적인 모바일 브라우저에서 NFC 태그는 URL을 여는 역할만 합니다. 웹페이지가 열리면 룰렛이 자동 시작됩니다.
- 방문 1회에 1번 회전하며 같은 화면에서 다시 돌리기 버튼은 없습니다.
- `localStorage`는 삭제하거나 조작할 수 있으므로 실물 경품 인증이나 부정 수령 방지에 쓰면 안 됩니다.
- 수집한 것은 **텍스트 도감 항목**이며 실제 포토카드 이미지나 히든 룸 게임은 아직 포함되지 않았습니다.
- 무료 정적 호스팅도 서비스별 정책 및 사용량 제한이 있을 수 있습니다.
- `file://`로 직접 열면 브라우저에 따라 저장이 제한될 수 있으니 HTTPS 사이트에 배포해 테스트하세요.
