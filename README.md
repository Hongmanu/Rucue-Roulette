# 루쿠 굿즈 룰렛

GitHub Pages에 `index.html`, `app.js`, `style.css`를 저장소 최상위에 업로드합니다. 기존 파일을 교체하고 Commit changes 하면 같은 URL에서 자동으로 새 버전이 배포됩니다.

## 확률
- 키캡(기본): 32%
- 키캡(찌부): 32%
- 키캡(할로윈): 32%
- 파우치: 3%
- 티셔츠: 1%

## 주의
- 이 버전은 브라우저에 당첨 횟수만 저장합니다. 서버 인증이 없으므로 새로고침·다른 기기·개발자 도구 등을 이용해 무제한 추첨하거나 결과를 바꿀 수 있습니다. 실제 굿즈 지급을 자동으로 확정하는 용도로는 사용하지 마세요. 행사에서는 운영자 확인이나 서버 검증이 필요합니다.
- 이전 수집 기록과 섞이지 않도록 저장 키를 `rucue-goods-collection-v1`으로 분리했습니다.
- NFC 자체를 판별하지는 않으며 URL을 직접 열거나 새로고침해도 회전합니다.
